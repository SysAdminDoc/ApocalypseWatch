ApocalypseWatch v0.2.1
Synthetic demonstration

1. Install Node.js 24 or newer from https://nodejs.org/ if it isn't installed.
2. Extract this entire ZIP into a new folder.
3. In that folder, run: node serve.cjs
4. Open http://127.0.0.1:3030 in your browser.

No package installation, provider account or internet connection is needed after
Node.js and this download are available. Keep the local server running while
using the demonstration. Opening web/index.html directly won't work.

The server binds only to this computer. It doesn't collect actual flights,
open a database or send notifications. The aircraft and history are synthetic.
It ignores any provider or notification credentials in your environment.

Use the theme buttons, compare chart ranges and download an evidence packet.
The sensitivity slider changes a preview, not the main dial. No reading here
predicts an emergency or establishes who is aboard an aircraft.

If port 3030 is occupied, set PORT to another free local port before starting.
Stop the server by terminating its process or closing its terminal.

Source and measured-data setup:
https://github.com/SysAdminDoc/ApocalypseWatch
